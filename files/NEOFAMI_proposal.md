### *The Famicom of Reiwa, dreamed into existence by AI.*

> 「見た目はファミコン、中身は令和。AIと一緒に、夢に見たオリジナルファミコンソフトを今すぐ動かす。」

---

## 1. コンセプト

**NEOFAMI（ネオファミ）** は、JavaScriptで実装された「令和のファミコン」仮想ハードウェア & AI駆動ゲーム開発フレームワークだ。

実機エミュレータではない。**ファミコンの"魂"だけを再現し、ハードウェア制約から完全に解放された新しい仮想機**である。

- **見た目はファミコン**：256×240ピクセル、NES標準54色パレット、8×8タイル、スキャンライン、CRTシェーダー
- **中身は令和**：120FPS、スプライト無制限、レイヤー無制限、CPU制約なし、TypeScriptでロジック記述
- **開発は対話**：「マリオ風横スク作って」と言えばAIがアセット・BGM・ステージ・コードを全部生成

レトロゲーマーが「あの頃やりたかったゲーム」を、ブラウザで一晩で形にできる。それがNEOFAMI。

## 3. 仮想ハードウェア仕様（NEOFAMI HARDWARE SPEC v1.0）

### 3.1 ディスプレイ
| 項目 | NES実機 | SMS実機 | NEOFAMI |
|---|---|---|---|
| 解像度 | 256×240 | 256×192 | **256×240（固定）** |
| マスターパレット | 54色 | 64色 | **NES 54 + SMS 64 + 自由RGB（無制限）** |
| 同時表示色 | 25色 | 32色 | **無制限** |
| フレームレート | 60Hz | 60Hz | **120FPS（60FPS互換モードあり）** |
| CRTフィルタ | なし | なし | **WebGLシェーダーで再現（ON/OFF切替）** |

### 3.2 スプライト / BG（v0.2 アップグレード）

**SMS方式の "1キャラ16色" を採用し、各スプライト/各BGタイルが独立した16色パレットを持てる。**

| 項目 | NES実機 | SMS実機 | **NEOFAMI** |
|---|---|---|---|
| スプライトサイズ | 8×8 / 8×16 | 8×8（合成可） | **8×8 / 16×16 / 任意（タイル合成自由）** |
| **1スプライトの色数** | **4色**（透明含） | **16色**（透明1+表示15） | **★16色**（透明1+表示15） |
| スプライトパレット数 | 4個共有 | 1個固定 | **★無制限（各スプライト独自パレット）** |
| 同時表示スプライト数 | 64個 | 64個 | **無制限** |
| 横並び制限 | 8個まで（欠ける） | 8個まで | **制限なし**（RETRO LOCKで再現可） |
| BG層 | 1層 | 1層 | **無制限（パララックス自由）** |
| BGタイル色数 | 4色 | 16色 | **16色 + マルチパレット切替自由** |
| タイル容量 | 8KB CHR ROM | 16KB VRAM | **無制限（PNG読み込みOK）** |

#### なぜ SMS方式が選ばれたか
- **NES（4色）の制約は厳しすぎて、肌・服・影・装飾を全部表現できない**
- **SMS（16色）はピクセルアートとして"ちょうどよい"豊かさ**：陰影・金属反射・装飾が表現可能
- NEOFAMIは **SMSの自由度 × NESの解像度・ピクセルサイズ感** をいいとこ取り
- レトロ感を維持しつつ「あのとき作りたかった絵」を実現できる甘い肩

#### パレットシステムの実装
```typescript
type Palette16 = [null, ...string[]]; // 透明 + 15色 hex
type Sprite = {
  tiles: TileData;      // 16x16ピクセル（or 任意サイズ）
  palette: Palette16;   // 各スプライト独自の16色
  paletteVariants?: Palette16[]; // 色違いキャラ用の追加パレット
};
```
キャラ色違いやチームカラー切替が `palette` フィールド差し替えだけで実現できる。

### 3.3 サウンド
NES準拠の **2A03互換APU** に加えて、人気拡張音源を標準搭載：

| 音源 | 説明 |
|---|---|
| Pulse 1 / Pulse 2 | 矩形波（NES標準） |
| Triangle | 三角波（NES標準） |
| Noise | ノイズ（NES標準） |
| DPCM | サンプリング再生（NES標準） |
| **VRC6 拡張** | 矩形波×2 + 鋸波（悪魔城伝説の音） |
| **MMC5 拡張** | 矩形波×2 + PCM |
| **N163 拡張** | 波形メモリ8ch（コナミの音） |
| **FDS 拡張** | FM風波形（ディスクシステムの音） |

実装は **Web Audio API + AudioWorklet** で低レイテンシ。`.nsf`ファイルもインポート可能。

### 3.4 CPU
- 6502エミュレーションは**しない**
- ゲームロジックは **TypeScript / JavaScript** で記述
- 「6502風の制約」をオプションで擬似的に課せる「**RETRO LOCK**」モード搭載
  - 例：1フレーム内のスプライト処理時間を仮想クロックで制限
  - チャレンジモード的に楽しめる

## 4. AIゲーム開発レイヤー（NEOFAMI STUDIO）

「全部入り」AI支援。**対話だけでゲームが完成する**。

### 4.1 AIエージェント構成

```
NEOFAMI STUDIO
├── PixelArtist Agent    : スプライト・BGタイル生成（NES制約準拠の8×8タイル）
├── Composer Agent       : チップチューンBGM/SE生成（.nsf形式出力）
├── LevelDesigner Agent  : ステージレイアウト・敵配置・難易度設計
├── Scripter Agent       : ゲームロジック生成（TypeScriptコード）
├── Director Agent       : 上記をオーケストレーションする総監督
└── Playtester Agent     : AIプレイヤーが実際にプレイしてバランス調整
```

### 4.2 開発フロー例

```
[User]: 「忍者が手裏剣投げる横スクアクション。和風で、ボスは大ムカデ」
   ↓
[Director] → 企画書ドラフト生成
[PixelArtist] → 忍者スプライト32パターン、和風BGタイル128種、ムカデボス
[Composer] → ステージBGM3曲、ボス曲、SE 20種
[LevelDesigner] → 全5ステージ、ボスパターン3段階
[Scripter] → 物理、判定、ステートマシン、シーン遷移コード
[Playtester] → 1000回プレイして難易度カーブ調整
   ↓
ブラウザで即プレイ可能 → PWA化してスマホにインストール可能
```

### 4.3 NEOFAMI Prompt DSL

簡易DSLで指示できる：

```neofami
@sprite ninja {
  style: "NES, 4-color palette, blue/black/white/skin"
  frames: [idle, run x4, jump, attack, hurt]
  size: 16x16 (2x2 tiles)
}

@bgm stage1 {
  mood: "tense, ninja, traditional Japanese pentatonic"
  channels: [pulse1, pulse2, triangle, noise]
  length: 60s, loop
}

@level stage1 {
  theme: "bamboo forest at night"
  length: medium
  enemies: [shuriken_thrower, ground_dog x3, mid_boss]
}
```

## 7. カートリッジ形式 `.neofami`

ゲーム1本 = 1個の `.neofami` ファイル（中身はZIP）：

```
mygame.neofami
├── manifest.json     # メタデータ（タイトル、作者、サムネ）
├── code/             # TSコード
│   ├── main.ts
│   └── scenes/
├── assets/
│   ├── sprites/      # PNG（8×8タイル）
│   ├── bg/           # PNG
│   └── audio/        # NSF / WAV / 自作NEOFAMI形式
└── ai_prompts/       # 生成に使ったプロンプト履歴（追加開発用）
```

ファイルダブルクリック → ブラウザで起動。配布もシェアも楽勝。
